Include what you were doing, what happened, and your iPhone model and iOS version. Leave out private notes, prices, and full backup files.

Back up or move your collection

Open More → Back Up & Restore → Create Backup File and save the file somewhere private. On the other iPhone, use Restore from Backup File in the same menu.

Export a spreadsheet

Open More → Export Spreadsheet (CSV) for a list of your bottles. To keep photos, shelves and wishlist items, use Create Backup File.

Remove your collection

Open More → Delete All Data. Manage copies you exported or shared separately.
